# Luna Voice

Первый экран вокальной практики на Next.js: фортепианные ноты движутся справа налево, а линия показывает высоту голоса с микрофона.

## Запуск

```sh
npm install
npm run dev
```

Откройте http://localhost:3000. Первый Play покажет проверку: выберите микрофон и реальный тип выхода, затем спойте пробную ноту. После успешного запуска последующие нажатия Play идут прямо к отсчёту. Настройка доступна отдельно и возвращается при ошибке микрофона. После успешной проверки нажмите «Начать практику». Для доступа с другого устройства нужен HTTPS. Рекомендуются наушники: иначе микрофон может принять звук фортепиано за голос.

## Практика и библиотека

В разделе «Библиотека» — шесть упражнений с фильтрами по цели, уровню и длительности. Есть избранное и недавние упражнения, сохраняемые локально. Занятие «Первые шаги» объединяет три упражнения с отдыхом и общим результатом. Модель и правила: [EXERCISES.md](docs/EXERCISES.md). История попыток и общие итоги доступны в разделе «Прогресс».

## Тренировка слуха

В разделе **Ear training** — восемь типов заданий: ноты, направление высоты, интервалы и их сравнение, аккорды, обращения, последовательности и лады. В каждом занятии 20 вопросов, повторное прослушивание и итог с разбором ответов. Поддерживаются английский, украинский и русский языки. Микрофон не нужен. Результаты этого раздела пока доступны только в текущем занятии. Подробности: [EAR_TRAINING.md](docs/EAR_TRAINING.md).

## История вокальной практики

История сохраняется в IndexedDB этого браузера: завершённые и прерванные попытки, результаты по нотам и итоги занятий. Есть календарь за 28 дней, статистика по упражнениям, сравнение совместимых попыток, ежедневная цель и напоминание внутри приложения. Историю можно экспортировать в JSON или удалить. При недоступном хранилище практика продолжается, а несохранённые данные остаются в текущей вкладке до повторной попытки записи. После подключения Supabase и входа данные аккаунта синхронизируются между устройствами. Гостевая история остаётся отдельной. Подробности: [HISTORY.md](docs/HISTORY.md).

## Аккаунты и Supabase

Кнопка «Войти» открывает вход по почте с паролем или через Google. После входа доступны имя, автоматическая синхронизация истории/настроек/избранного, перенос гостевой истории и удаление аккаунта после повторного входа. Офлайн-изменения сохраняются в очереди IndexedDB; каждое пространство аккаунта отделено от гостя и других пользователей.

Подключение: выполните [SUPABASE_SETUP.sql](SUPABASE_SETUP.sql) в SQL Editor, заполните `.env.local` по [.env.example](.env.example), настройте ссылки в письмах и провайдер Google по [AUTH_SETUP.md](docs/AUTH_SETUP.md). Подробные шаги, правила конфликтов и резервные копии: [SUPABASE.md](docs/SUPABASE.md). Без настроенного Supabase работает гостевая версия.

## Первое упражнение

- До–Ре–Ми–Фа–Соль–Фа–Ми–Ре–До на слог «Ма».
- Диапазон сдвигается по полутонам от C2–G2 до F5–C6; темп 50–110 BPM. Используются 49 WAV-сэмплов C2–C6. Для существующей базы выполните [SUPABASE_AUDIO_UPDATE.sql](SUPABASE_AUDIO_UPDATE.sql), чтобы сохранять результаты ниже C3. При 75 BPM нота длится 1,6 секунды, промежуток — 0,3 секунды. Отсчёт всегда 3 секунды.
- В проверке микрофона можно получить предложение диапазона по удобной устойчивой ноте, послушать его края и скорректировать вручную. Это не измерение полного вокального диапазона.
- Результат содержит оценку каждой ноты, долю времени с распознанным голосом, время выше/ниже цели и одну подсказку. Можно повторить отдельную ноту, трудный фрагмент или всю лесенку.
- Диапазон, темп каждого упражнения и громкость сохраняются локально вместе с историей результатов.
- Начало прямоугольника пересекает пунктир одновременно с началом фортепианного семпла из `public/audio/piano`.
- Процент результата — доля времени звучания целевых нот, когда голос находится в пределах ±50 центов (половина полутона). Молчание и другая октава считаются промахом; отсчёт, промежутки и пауза не учитываются.
- Перед пением доступны настройка по тишине, ручная поправка задержки и измерение по трём сигналам с наушником у микрофона. Настройки сохраняются для устройства.
- По умолчанию выбран режим динамиков без процента: эталон может попадать в микрофон. Для оценки выберите используемые наушники.
- Кнопка наушников запускает прослушивание без микрофона и оценки.
- Пауза останавливает аудиочасы и движение; уход на другую вкладку автоматически ставит упражнение на паузу.

Аудио обрабатывается локально через Web Audio API, не записывается и не отправляется на сервер. YIN определяет основной тон в диапазоне примерно 65–1100 Гц. Влияние акустики, микрофона и задержки Bluetooth требует проверки на реальных устройствах; измерение задержки проверено на синтетическом тракте, испытания гарнитур ещё нужны.

## Дизайн и план развития

Оформление STUDIO использует [Manrope](https://fonts.google.com/specimen/Manrope) для интерфейса и [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) для нот и числовых показателей. Шрифты подключены через `next/font/google` с кириллицей и латиницей. При первой сборке нужен доступ к Google Fonts; браузер получает файлы шрифтов с сервера приложения.

Поэтапный план до полноценного приложения: [ROADMAP.md](./ROADMAP.md).

## Проверки

```sh
npm test
npm run lint
npm run build
npm run test:browser
```

Сценарии облачного аккаунта требуют отдельной тестовой сборки и `LUNAVOICE_CLOUD_TESTS=1`, см. [инструкцию](docs/SUPABASE.md#автоматические-браузерные-проверки). SQL и восстановление резервной копии проверяются через `npm run test:database` с временным локальным PostgreSQL.

Если среда блокирует локальные порты, используемые Turbopack для обработки CSS, сборку можно проверить командой `npm run build -- --webpack`.

Тесты проверяют высоту чистых сигналов и сигналов с обертонами при 44,1/48 кГц, тишину, границы попадания, неверную октаву и наличие семплов. Реальное пение и разрешения микрофона нужно дополнительно проверить в браузере.

## Структура

- `app/page.tsx` — экран практики.
- `app/lib/audio/` — аудиосессия, проверка сигнала, оценка, задержка и настройки.
- `app/hooks/use-audio-engine.ts` — связь движка с React и жизненным циклом страницы.
- `app/components/audio-setup.tsx` — проверка микрофона и настройка звука.
- `app/components/pitch-canvas.ts` — сетка, движущиеся ноты и линия голоса.
- `app/lib/pitch.ts` — определение высоты и музыкальные преобразования.
- `app/lib/exercises.ts` — каталог упражнений и короткое занятие.
- `app/lib/library.ts` — локальные списки избранного и недавних упражнений.
- `app/lib/history/` — модель истории, IndexedDB, миграции и очередь сохранения.
- `app/hooks/use-history.ts` — подписка на события попыток и состояние истории.
- `app/components/progress-view.tsx` — история, календарь, сравнение и ежедневная цель.
- `app/lib/session.ts` — состояние занятия и общая оценка.
- `app/lib/practice.ts` — темп, транспонирование, фрагменты, подбор диапазона и пути семплов.
- `app/lib/practice-feedback.ts` — подсказки и выбор трудного фрагмента.
- `app/components/practice-result.tsx` — подробный результат и повтор.
- `app/lib/cloud/` — клиент Supabase и отправка/получение изменений.
- `app/components/account-view.tsx` — вход, профиль, перенос гостя и управление аккаунтом.
- `supabase/migrations/` — серверная схема и правила доступа.
- `app/globals.css` — оформление для компьютера и телефона.

Подробности первого этапа: [аудиоядро и оценка](docs/AUDIO_ENGINE.md), [автоматические проверки и приёмка на устройствах](docs/AUDIO_TESTING.md). Для браузерных тестов нужен установленный Google Chrome и предварительная production-сборка; реальный микрофон не используется.
