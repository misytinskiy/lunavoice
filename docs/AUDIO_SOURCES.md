# Источники фортепианных семплов

Обновлено: 15 сентября 2026.

## public/audio/piano/*.mp3

По сообщению автора проекта, файлы самостоятельно нарезаны из звучания пианино в **FL Studio**. Аудиофайлы предоставлены автором вместе с проектом; внешние записи или новые звуковые библиотеки в ходе разработки не добавлялись.

Конкретный инструмент/плагин, пресет, версия и лицензия исходного набора звуков пока не указаны. Самостоятельная нарезка описывает способ получения файлов; условия распространения отдельных семплов исходного инструмента ещё не проверены. Пункт проверки условий в ROADMAP.md остаётся открытым до уточнения инструмента и его условий.

В текущей библиотеке используются C3–C6. Наличие всех файлов для всех разрешённых транспозиций проверяется автоматически до сборки тестами; при запуске движок загружает и декодирует нужные файлы до начала воспроизведения. У C♯3 исходное имя `С#3.mp3` содержит кириллическую «С»; загрузчик учитывает его без переименования оригинала.
