# Каталог упражнений

30 упражнений в пяти разделах: Звучание, Чёткость, Высота, Гибкость, Ступени.
24 новых упражнения — собственные последовательности по принципу предоставленных визуальных примеров, а не точная расшифровка Vocalista. Прежние шесть ID и последовательности сохранены для истории.

Определения: `app/lib/exercises.ts`. Интервалы заданы в полутонах относительно начальной ноты; длительности и паузы — в долях. Слоги задаются для каждой ноты. Миниатюры отражают реальную последовательность и относительные длительности; вертикальный масштаб индивидуален для карточки.

Оценка измеряет попадание в высоту, но не качество тембра и произношения. Разделы обозначают задачи практики, а не отдельные способы оценки.

## Обновление Supabase

Для существующей базы выполните весь `SUPABASE_EXERCISES_UPDATE.sql` в SQL Editor. Обновляется разрешённый список упражнений в RPC: результаты, избранное, темпы и последнее упражнение. История не удаляется. Пока миграция не применена, новые записи сохраняются локально, но их синхронизация может блокировать очередь; после обновления повторите синхронизацию.

Для новой базы `SUPABASE_SETUP.sql` уже включает миграцию 003. SQL не нужно выполнять при работе гостем.

## Проверки

Автотест каталога проверяет наличие аудиофайлов для всех допустимых тональностей. Браузерные тесты проверяют разделы, избранное, выбор упражнения и мобильную ширину. Локальная проверка PostgreSQL применяет миграцию повторно и проверяет сохранение новых записей вместе с существующими проверками изоляции аккаунтов.
